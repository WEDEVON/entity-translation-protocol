# Source Priority Prompt

## Purpose

Use this prompt at the beginning of a project or major review round to freeze the translation standard before editing.

## Required Inputs

- target locale
- target region
- known source classes
- known editorial or legal constraints
- known fallback policy

## Required Outputs

- one ordered source-priority list
- one explicit target locale statement
- one explicit target regional convention statement
- one fallback policy statement
- one note on unresolved source ambiguity, if any

## Prompt

Before editing translations, define the source-priority order for this project.

List:

- target locale
- target regional convention
- authoritative sources
- consensus sources
- dictionary or style-guide support
- fallback policy

## Completion Criteria

This prompt is complete only when the source-priority order is explicit enough to guide later review and promotion decisions.
