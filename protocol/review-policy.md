# Review Policy

## Review Priority

Always review in this order:

1. high-exposure entities
2. unresolved `fallback`
3. unresolved `partial_fallback`
4. repeated token gaps
5. long-tail cleanup

## Review Outputs

Each review round should update at least one of:

- manual full-name map
- token maps
- generated full-name map
- review queue
- decision log
