# Source Policy

## Goal

Translation quality depends on source discipline more than on map size.

## Define Source Classes

Each project should define source classes such as:

- official local-language source
- official primary-language source
- trusted regional media
- internal editorial standard
- reference dictionaries or transliteration rules
- generated fallback

## Source Register

Keep a source register that records:

- source name
- source type
- access method
- scope
- trust level
- notes

Use `templates/source-register.csv` as a starting point.

## When Sources Conflict

Use the project priority order.

Do not resolve conflicts ad hoc during editing.
