# Cross-Language Person Name Example

## Example Scenario

Source language:

- English person names

Target language:

- Japanese

## What Changes

- the target style guide
- script validation rules
- transliteration rules
- local consensus sources

## What Does Not Change

- source priority must still be defined
- manual and generated assets should still be separate
- audit output should still classify confidence
- high-exposure entities should still be fixed first

## Operational Transfer

Even when the destination script changes completely, the same pipeline still applies:

- source policy
- normalization
- audit classification
- promotion discipline
- release backups
